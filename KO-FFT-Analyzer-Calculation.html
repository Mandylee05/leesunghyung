FFT 분석기 페이지로 돌아가기

1. Sampling 확인

시간 간격과 Sampling 주파수

주파수 분해능과 Nyquist 주파수

여기서
  dt : 데이터 사이의 시간 간격
  t 0, t N−1 : 첫 데이터와 마지막 데이터의 시간
  N : 데이터 수
  F s : Sampling 주파수
  Δf : 주파수 분해능
  f Nyq : Nyquist 주파수

FFT 결과는 Sampling 조건에 따라 정해지기 때문에, 우선 시간 간격(dt)과 데이터 수(N)를 확인해야 합니다.
Sampling 주파수 Fs = 1/dt의 절반인 Nyquist 주파수보다 높은 성분은 Aliasing으로 왜곡되고, 주파수 분해능은 Fs/N으로 정해집니다.
내진검증의 관심 범위가 0.5~50 Hz이므로, Nyquist 주파수가 50 Hz보다 충분히 높은지 먼저 봅니다.

2. FFT 계산

Discrete Fourier Transform(DFT)

각 주파수 칸의 주파수

여기서
  X[k] : k번째 주파수 칸의 FFT 결과(복소수)
  x[n] : 시간이력의 n번째 데이터
  k, n : 주파수 칸 번호와 데이터 번호
  N : 데이터 수
  j : 허수 단위
  f k : k번째 주파수 칸의 진동수
  F s : Sampling 주파수

FFT는 시간이력을 여러 주파수의 정현파 합으로 분해하는 DFT를 빠르게 계산하는 방법입니다.
각 주파수 칸은 k·Fs/N의 주파수에 대응하고, 결과는 그 주파수 성분의 크기와 위상을 가진 복소수입니다.
한마디로, 시간 신호 안에 어떤 진동수가 들어 있는지 꺼내 보는 단계라는 뜻입니다.

3. Amplitude Spectrum

양측 진폭

단측 진폭

여기서
  P 2[k] : 양측 진폭
  P 1[k] : 단측 진폭
  |X[k]| : FFT 결과의 크기
  N : 데이터 수

FFT 결과의 크기는 데이터 수에 비례해서 커지기 때문에, N으로 나눠 실제 진폭으로 바꿔야 합니다.
실수 신호의 FFT는 양의 주파수와 음의 주파수가 대칭이므로, 한쪽만 남기고 2배를 해서 단측 진폭을 구합니다.
이렇게 해야 Spectrum의 값을 원래 가속도 단위(G)로 읽을 수 있습니다.

4. Peak 검출

Peak 조건

Peak 최소 간격

여기서
  P 1[k] : k번째 칸의 단측 진폭
  h : Peak 최소 진폭(0.05 G)
  k i , k j : 이웃한 두 Peak의 주파수 칸 번호
  Δf : 주파수 분해능
  G : 중력가속도 단위의 가속도

Spectrum에서 Peak가 나타나는 진동수는 구조물이나 입력이 가진 지배 진동수를 뜻합니다.
프로그램은 이웃 값보다 크고 최소 진폭을 넘는 점을 Peak로 찾고, Peak 사이에 최소 간격을 두어 잡음 때문에 생기는 작은 Peak를 걸러 냅니다.
이렇게 찾은 진동수가 내진해석에서 먼저 확인해야 할 주요 진동수가 됩니다.

예제문제 2

층 가속도 Spectrum 예제

이번 예제에서는 원전 건물의 합성 층 가속도 시간이력(N = 4000, dt = 0.005 s, Fs = 200 Hz, PGA 1.20 G)을 분석합니다.
이 기록은 0.5~50 Hz로 대역을 제한한 뒤, Damping 3 %인 구조 모드 세 개를 통과시켜 만든 데이터입니다.
FFT 분석기의 주파수 분해능은 0.05 Hz이고, 최소 진폭 0.05 G를 넘는 지배 Peak로 3.20 Hz(0.123 G), 8.35 Hz(0.104 G), 14.20 Hz(0.099 G)를 찾습니다.
