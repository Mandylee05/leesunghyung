PyMathcad Worksheet

PyQt5와 pint로 만든, Mathcad Prime 방식의 Python 계산서 프로그램입니다.
수식 영역에서 단위, 사용자 함수, Vector, if 판정을 쓸 수 있고, 값을 입력하는 즉시 다시 계산됩니다.
그리고 Mathcad Prime .mcdx 파일을 열거나 Excel 표를 넣을 수 있고, 보고서용 A4 PDF로 출력할 수도 있습니다.

다운로드

계산 단계

01

자세히 보기

Unit
(단위가 있는 값)

kg, kN, MPa 같은 단위를 붙여 숫자를 입력하면, 등호 뒤에 쓴 단위로 결과를 보여줍니다.

02

자세히 보기

Function
(사용자 함수와 논리)

SRSS(a, b, c) 같은 함수를 계산서 안에서 정의하고, if()로 각 검토 항목에 O.K 또는 N.G를 표시합니다.

03

자세히 보기

Array
(Vector와 합계)

matrix()로 Vector를 만들고, T[k]로 한 행을 읽습니다.
length, max, min, sum 같은 함수는 전체 값에 한 번에 적용됩니다.

04

자세히 보기

PDF 출력
(A4 Worksheet)

A4 페이지의 0.5 cm 격자에 영역을 배치하고, 완성된 계산서를 고해상도 PDF로 내보냅니다.

사용 방법

01

우선, 영역을 넣을 위치를 클릭하고 Math를 누른 뒤 m := 412 kg 같은 정의를 입력합니다.

02

분수, 거듭제곱, 루트, 그리스 문자는 Operators, Symbols, Programming 메뉴나 / ^ \ 키로 입력합니다.

03

단위는 Units 메뉴에서 고릅니다. F = kN처럼 이름 뒤에 = 와 단위를 쓰면, 결과가 그 단위로 표시됩니다.

04

격자 위에 영역을 배치합니다. ≡로 쓴 전역 정의가 먼저 계산되고 나머지는 위에서 아래로 계산되기 때문에, 무엇을 바꾸든 바로 다시 계산됩니다.

05

계산서는 .mcalc로 저장해서 나중에 다시 열 수 있습니다. Mathcad Prime .mcdx 파일을 열거나, Mathcad에서 복사한 영역을 붙여넣을 수도 있습니다.

06

PDF Output을 누르면 모든 페이지가 화면과 같은 A4 PDF로 출력됩니다. 보고서에 바로 첨부하면 됩니다.
