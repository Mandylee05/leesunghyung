PyMathcad Worksheet 페이지로 돌아가기

1. Unit과 계산

정의와 계산

암시적 Unit

여기서
  := : 정의
  = : 계산(결과 표시)
  ≡ : 전역 정의
  E : 탄성계수(전역 정의 예)
  g : 중력가속도

손 계산서에서 가장 흔한 실수는 단위 변환입니다.
프로그램은 값마다 Unit을 붙여 정의하고 계산할 때 자동으로 환산하므로, kN과 N, mm와 m가 섞여도 결과가 맞습니다.
Mathcad처럼 식과 단위를 함께 보여 주기 때문에 검토하기도 쉽습니다.

2. Function과 논리

사용자 Function

조건

여기서
  f(x, y) : 사용자 Function
  SRSS(a, b, c) : 제곱합의 제곱근
  if(cond, a, b) : 조건이 참이면 a, 아니면 b
  IR : 조합 응력비
  f t , F t : 인장응력과 허용 인장응력
  f v , F v : 전단응력과 허용 전단응력

같은 검토를 여러 부재에 반복할 때는 식을 Function으로 정의하면 편리합니다.
프로그램은 사용자 Function과 if() 같은 조건식을 지원해서, 허용값과 비교한 판정(O.K/N.G)을 자동으로 표시합니다.
이렇게 하면 판정 기준이 계산서 안에 그대로 드러납니다.

3. Array와 합계

Vector와 Index

합계

여기서
  T : 값을 묶은 Vector
  T k = T[k] : T의 k번째 값
  ORIGIN : 첫 번째 Index 번호
  sum(expr, i, a, b) : i = a부터 b까지 expr의 합

Bolt나 Node처럼 같은 종류의 값이 여러 개일 때는 Vector로 묶어서 다룹니다.
Index로 각 값을 꺼내 쓰고 합계 기호로 한 번에 더할 수 있기 때문에, 표 계산을 식으로 나타낼 수 있습니다.
그래서 Excel 표 대신 검토할 수 있는 식으로 계산을 남길 수 있습니다.

4. Worksheet와 PDF

페이지 격자

계산 순서

계산서는 위에서 아래로 계산 순서가 분명해야 합니다.
프로그램은 페이지 격자에 맞춰 식과 설명을 배치하고, 정의된 순서대로 계산한 뒤 A4 PDF로 출력합니다.
덕분에 제출용 계산서를 바로 만들 수 있습니다.

예제문제 2

Anchor Bolt 검토 예제

이번 예제에서는 Nodal Load 추출에서 얻은 반력으로, 412 kg 캐비닛의 M12 Anchor Bolt를 SSE(Damping 3 %) 조건에서 검토합니다.
우선, SRSS로 V = 5.443 kN, T = 11.915 kN을 구하고, f_t = 141.3 MPa, f_v = 64.6 MPa를 허용응력 300 MPa, 160 MPa와 비교합니다.
상호작용비는 0.385이므로 if()가 O.K를 표시하고, 계산서는 A4 PDF로 출력됩니다.
