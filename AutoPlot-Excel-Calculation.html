EXAMPLE 2

Test Prediction Example

This example predicts the qualification test that will be run with the New RRS of step 4. The measured test IERS is multiplied by NewRRS(f) / RRS(f) on a merged frequency axis, while the analysis IERS keeps Target_RRS = RRS. The predicted test IERS envelopes the analysis IERS in every group and direction, with a minimum margin of 1.10 in X, so no ratio label remains.
