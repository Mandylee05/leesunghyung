SRS 분석 페이지로 돌아가기

1. 직접적분법

SRS는 고유진동수가 다른 여러 1자유도계에 같은 가속도를 넣었을 때, 각 계의 최대 응답을 모은 곡선입니다.
직접적분법은 위의 운동방정식을 시간 영역에서 한 단계씩 적분해서 응답을 구하기 때문에, 원리가 직관적이고 어떤 입력에도 그대로 쓸 수 있습니다.
다만, 정확도를 위해 시간 간격을 충분히 작게 잡아야 합니다.

2. 전달함수법

전달함수법은 입력을 FFT로 주파수 영역으로 바꾼 뒤, 1자유도계의 전달함수를 곱하고 다시 역FFT해서 응답을 구합니다.
주파수마다 곱셈만 하면 되기 때문에, 많은 진동수를 한꺼번에 계산할 때 빠릅니다.
직접적분법과 같은 결과를 다른 경로로 구하는 셈이라서, 두 결과를 비교하면 계산을 서로 검증할 수 있습니다.

지진 입력 예제

이번 예제에서는 합성 지진 가속도 시간이력(20 s, PGA 0.30 g, dt = 0.001 s)에 두 방법을 모두 적용합니다.
Damping은 원자력발전소 기기 내진검증의 SSE 값인 3 %(OBE는 2 %)를 쓰고,
내진검증에서 FRS(층응답스펙트럼)가 다루는 0.5~50 Hz 범위에서 1/3 옥타브 간격으로 SRS를 계산했습니다.
두 방법의 결과는 0.3 % 이내로 일치하고, SRS 최대값은 25.4 Hz에서 1.012 g입니다.
