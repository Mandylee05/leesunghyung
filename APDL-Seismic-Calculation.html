2. Modal Analysis

Eigenvalue Problem

Participation Factor

where
  K, M : stiffness and mass matrices
  ω i : natural circular frequency of mode i [rad/s]
  φ i : mode shape of mode i
  f i : natural frequency of mode i [Hz]
  Γi : participation factor of mode i
  r : influence vector of the excitation direction
  m eff,i : effective mass of mode i
  M total : total mass of the model

Response Spectrum analysis is based on the natural frequencies and mode shapes of the structure, so a Modal analysis comes first.
Modal analysis solves the eigenvalue problem formed by the stiffness and mass matrices, and the Participation Factor tells how strongly each mode responds to an earthquake in each direction.
This step identifies the modes that govern the seismic response.

3. Response Spectrum

Spectral Acceleration

Mode Combination

where
  S a (f i ) : spectral acceleration at fi read from the RRS
  ζ : damping ratio (3 %)
  q i : modal response of mode i
  Γi , ω i : participation factor and circular frequency of mode i
  R i : response of mode i
  R ZPA : residual rigid response at the ZPA
  R : combined response (SRSS)

The peak response of each mode is the spectral acceleration at that mode's frequency multiplied by its Participation Factor.
Modal peaks do not occur at the same time, so they are not simply added but combined with a method such as SRSS.
For nuclear equipment, the effect of closely spaced modes is also included according to RG 1.92.

4. Load Combination

Direction Combination

Result Set Numbers

where
  R X , R Y , R Z : responses to the X, Y and Z excitations
  R XYZ : combined three-directional response
  SetX, Y, Z : result set numbers of each direction

  n Mode : number of extracted modes

An earthquake acts in X, Y and Z at the same time, so the results for each direction must be combined into one.
The program writes commands that combine the three directions by SRSS and assigns result set numbers so stresses and reactions can be checked right away.
The combined result is the final response used in the design check.

EXAMPLE 2

Top Payload Change Example

This example adds four 60 kg instruments to the top frame (2000 mm) of the same steel cabinet and repeats the analysis with the horizontal and vertical RRS (3 % damping, 0.5 to 50 Hz). The program reads the new model with 244 elements and writes the same modal and spectrum code. The first mode drops from 17.77 Hz to 10.57 Hz, close to the 8 to 10 Hz peak of the horizontal RRS, so the spectral acceleration rises from 2.67 g to 4.29 g. The combined SRSS stress in the 700 mm shelf beam becomes 241.5 MPa against the allowable 211.5 MPa (ratio 1.14), so the frame must be reinforced or the top instruments relocated. The frequencies and stresses in these examples come from a Python beam model of the same cabinet that follows the generated APDL steps.
